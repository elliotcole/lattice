# Keyboard & Interaction Reference

This is a context‑based reference for Tuning Lattice shortcuts. Most commands only work when the canvas is focused (not when typing in inputs or dialogs).

---

## 2D / 3D Canvas

**Core actions**
- Shift‑click: add a node
- Option‑click: remove a node
- Z‑click: enter Z‑axis mode from a node (X / Y also available)
- C‑click: add a custom ratio (4th–7th dimension)
- Hold I + click: open Calculate Interval
- Hold L + press & hold: start LFO on a node
- Hold M + click: mute / unmute a node (ghost — visible but silent, skipped in patterns)
- Hold N + click: center view on the node
- Click a muted node: unmute it
- Hold T: label triangles
- Hold O + click: change playback octave
- Hold F + click: set fundamental
- Space: toggle pattern play/stop
- Shift+Space: release all playing nodes

**Navigation**
- 2D: drag to pan, scroll to zoom
- 3D: drag to rotate, arrows to pan, scroll to zoom

---

## Axis Edit Modes (X / Y / Z)

- Click a node to set the axis anchor
- ESC: exit axis mode
- Double‑click empty canvas: exit axis mode

---

## Distance Edit Mode

- Drag between nodes to create distance lines
- Drag label to slide, drag line to curve
- Option‑click line: delete
- Double‑click label: edit interval name
- ESC or double‑click background: exit

---

## Interval Overlay (Microtonal Intervals)

- Click node: show connections
- Click visible connection: listen
- Double‑click canvas: exit

---

## Layout Mode

**General**
- Drag: adjust positions
- Option‑click: reset adjustments
- Hold Shift: lock moves to 1 direction
- Page Layout: use `Add Custom Text`
- Space: adjust per‑axis spacing
- Double‑click node: change shape
- Double‑click axis legend: adjust angle

**Axis legend edit**
- Delete/Backspace: delete axis legend (undoable)
- ESC: exit legend edit

---

## Align Modes (Layout)

- X‑Align: click anchor node, then click nodes to align X
- Y‑Align: click anchor node, then click nodes to align Y
- Straighten: click two nodes to set the line, then click nodes to align
- ESC or double‑click canvas: exit align mode

---

## Snapshots

**Number slots (1–0)**
- Option + number: save snapshot
- Number: recall snapshot

**Letter slots (QWERTY grid, when enabled)**
- Option + letter: save snapshot
- Letter: recall snapshot

> Notes
> - Snapshot key input only works when the canvas is focused.
> - “Letters active” must be enabled for letter slots.

---

## Pattern / Playback

- Space: play/stop pattern
- Shift+Space: release all playing nodes

---

## Editing dialogs

- ESC closes most dialogs
- Enter/Return submits most dialogs (except where multiline input is expected)
