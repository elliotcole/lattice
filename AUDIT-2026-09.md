## 2. Confirmed defects (new since June)

Ranked by user impact. H = headless-verified, C = confirmed by code reading in this session.

### Audio

1. **H — One-shot plucked/resonant notes throw.** `startVoice` calls `oscillator.stop(stopAt)` on worklet nodes (main.js:14988) with no `usesWorklet` guard; `stopVoice` has the guard (15017), the one-shot branch doesn't. `TypeError: stop is not a function` escapes after the note sounds, so `sendMidiOutNoteOn` and looper capture (14991+) are skipped for every one-shot worklet note.
2. **C — Worklet processors are never released.** Both worklets always `return true` (`karplus-worklet.js:55,59,79`; `modal-resonator-worklet.js:83,87,107`); main never posts a stop message; `onended` cleanup only attaches when `.start` exists (14962), i.e. never for worklets. Every plucked/resonant note leaves a processor rendering forever (resonator: six IIRs + `Math.random()` per sample). CPU climbs monotonically per session.
3. **C — Resonator partials drift during glides.** `modal-resonator-worklet.js:64–71` rescales `mode.freq` in place each block but only updates `baseFreq` on jumps >0.5 Hz; the sub-0.5 Hz steps from `setTargetAtTime` compound (~10 cents per glide, permanent). Karplus has the mirror bug: any >0.5 Hz step re-plucks (`karplus-worklet.js:43–47,64–66`), audible during retune.
4. **C — First worklet note is always a sine.** `addModule` is never awaited (main.js:18040–18072); the fallback path runs silently and errors are swallowed with `.catch(() => {})`. Also: both worklets are inlined as `data:` URLs only because they sit under Vite's 4 kB threshold; crossing it silently changes delivery.

### Serialization / state

5. **H — Snapshot recall with "Restore view" or "Restore synth" unchecked resets to boot defaults.** `prepareSnapshotStateForRecall` (3337) deletes `view`/`synth` to mean "leave alone", but `applyPresetState` → `normalizePresetStateWithDefaults` → `deepMergePresetState` (24086) refills every absent key from the boot snapshot. Repro: zoom 2.0, volume −30, both toggles off, save slot; change to 0.6 / −40; recall → zoom 1, volume −12. The toggles do the opposite of their label whenever the user is away from defaults.
6. **H — A malformed URL or file kills the app at boot.** `applyPresetState` runs at module top level with no try/catch (29060); `hashchange` likewise (29122). `applyPresetLayoutCustomLabels` (25046) dereferences entries with no null check. A `#s=` hash encoding `{layout:{customLabels:[null]}}` throws, and the 2,400 lines of event wiring after it (including `initTheme`) never run. The file-load path has a catch but no rollback, so a bad file leaves a half-applied session.
7. **C — Snapshot-set export cannot represent deletions.** `diffSnapshotState` (3529) iterates only `Object.keys(next)`; `pruneEmptyPresetCollections` (23871) removes empty collections before diffing. Delete a custom node (or unmute everything, or clear triangles) in a slot, export, import → the slot has the base's collection back. In-memory recall is fine; only export→import corrupts. The checked-in fixture doesn't exercise this.
8. **C — Two per-node maps use positional ids that shift on rebuild.**
   - `noteSpellings` is keyed by `node.id` (15768, persisted at 24005); `rebuildLattice` remaps voices and looper events via `nodeIdRemap` (28259) but not spelling overrides. `maybeExpandAxisRangesForActivation` (18801) auto-widens the grid, so activating an edge node silently reassigns every spelling override to a different node.
   - Distance edges use `custom:<runtime id>` (`getDistanceNodeKey` 22471) while custom nodes are persisted by array position; `removeCustomNode` (5885) never prunes edges; `applyPresetCustomNodes` skips unresolvable entries (24151) and shifts every later id. Fixture 32 carries `"custom:200000|grid:12,0,0"`, so Phase 4 needs a migration for this key form. The stable `custom:x,y,z|slot` key already exists (`getSnapshotNodeKey` 3376) and is simply not used here.
9. **C — F+click rebase forgets distance edges.** `rebaseLatticeFromNode` (6693) shifts octave offsets, volume limits, and line-label overrides but has zero references to `distanceSelectedEdges`/`distanceEdgeOverrides`. After a rebase, every saved distance edge names whichever nodes moved into those exponent slots.
10. **C — `history.replaceState` per pointermove during drags.** Line-label drag (16314) and layout node drag (16567) call `updatePresetUrl` directly, bypassing the 250 ms debounce, each with a full `getPresetState()` + LZ compress. Safari throws `SecurityError` past 100 calls/30 s and aborts the handler; there is no try/catch around `replaceState` (24196).
11. **C — Persisted play-state controls don't schedule a URL update.** Tempo slider, pattern length slider and mode, and the LFO play toggle (31364–31435) mutate values that `serializePlayState` writes, without `schedulePresetUrlUpdate()`. The envelope sliders three lines up use `bindPresetInputHandler` correctly.
12. **C — Bare `localStorage` at module top level.** `initTheme` (21899), `toggleTheme` (21885), `onThemeSelectChange` (21895) are the only three of 13 storage sites without try/catch; `initTheme` runs during module evaluation (31468). With site data blocked, the app is a blank canvas.
13. **C — `applyPresetSnapshotPayloadState` (25469) reads six `snapshot*` keys that no preset ever writes**, and nulls `snapshotBaseState` on every preset load and snapshot recall as a side effect.

### Renderer parity

14. **C — Interval Overlay (comma connections) is canvas-only.** `draw()` calls `drawCommaConnections` and dims other edges (13592, 13957); `buildLayoutSvgString` has no reference to it, and `setLayoutMode` doesn't clear the flag. SVG/PDF export silently drops the overlay. This is the only renderer gap found; every other toggle checked (line thickness, black edges, line labels, key mappings, custom labels, orphan guides, HEJI, distances, triangles, node shapes) goes through shared helpers in both renderers. June's "guaranteed divergence" is narrower than feared.

### Shared core (`src/lib/pitch.js`)

15. **C — `normalizeRatioToOctave(num ≤ 0, den)` loops forever** (155–159; guard at 148 checks only finiteness and `den === 0`). Latent today (all three apps clamp inputs), but it's the shared API contract and both surviving `reduceToOctave` copies have the same hole.
16. **C — `getHejiAnnotationForAxisRatios(axisRatios, undefined)` throws** at 347 while 346 and 355 coerce. `hasAccidental("Fx")` returns false (320) while `getAccidentalType` counts `x` (324); main imports `hasAccidental` and never uses it, and also imports `accidentalToString` unused.
17. **C — Float ceiling is silent.** `reduceFraction(2**60, 3**37)` returns a wrong reduction; `gcd(3**40, 3**39)` → 4.05e18. No `Number.isSafeInteger` anywhere. Unreachable within main's ±16 axis range; becomes real the day limits widen before the monzo/bigint work lands.

### Satellites

18. **C — Tuner calibration lazy-load poisons its cache.** `calibrationLoadPromise` memoises a rejected promise (tuner/main.js:3404–3435); one network failure means every later click re-rejects with no retry, and the `cal-run`/`cal-reset` async handlers have no catch.
19. **C — Tuner mobile redirect has no way back** (tuner/index.html:6–18). Coarse pointer + ≤1024 px sweeps iPads-in-portrait and touch laptops to `/mobile/` permanently; no query flag, no link back; `/tuner/index.html` → `/tuner/index.html/mobile/` (404).
20. **C — Deck import script is lossy.** `scripts/import-tuning-the-ear.mjs:19` hardcodes `…/Diagrams v2` (CLAUDE.md still says `Diagrams/`); slug collisions are silently suffixed `-2` (122–126); bad JSON is skipped with exit 0 after `rmSync` of the diagrams dir, so a re-import can drop slides. Manifest and diagrams are otherwise consistent (38 ↔ 38); slide 33 is absent from the numbering.
21. **C — A missing deck diagram is invisible to the user** (`console.warn` only, main.js:28783).

### Process / build

22. **C — The 1 MB "interval-names" chunk is mostly oscillator wavetables.** `dist/assets/interval-names-*.js` (1,039 kB, 169 kB gzip) is the shared chunk between main and overtones. It holds ~130 kB of `interval-names.json` and ~900 kB of `web-audio-oscillators` periodic-wave coefficients, `modulepreload`ed on first paint for both apps. Overtones uses one waveform (`semisine`); main needs only the type list at startup. On top of that, main.js imports the JSON statically (line 6) *and* fetches it again at runtime (22759), so the raw JSON ships and downloads twice.
23. **C — CI builds twice.** `check:regression` runs `npm run build` internally, then `deploy.yml` builds again. Tests run only on push to `main`; there is no PR/branch workflow and no `concurrency` group.
24. **C — Font licences are absent.** 40 OFL fonts ship into `dist/assets/` (≈10 MB); no `OFL.txt`, no manifest. OFL §1/§4 require the licence to travel with redistributed fonts. `Lato-Sargam.woff2` is unreferenced. HEJI2Text's terms should be confirmed with Plainsound.
25. **C — Commit `f99ffd2` has the wrong message** ("allow creating press list before catalog number set" is a Phase 2 pitch.js hookup). Already on `main`; note it here rather than rewrite.
26. **C — `presentation.html`** is still tracked, still not a Vite entry, links `./src/theme.css` directly, and is linked from nowhere. Orphan, not a live broken link.

### UI / accessibility

27. **C — Solarized Light fails AA for all secondary text.** `--chrome-muted-ink` on `--chrome-bg` computes to 2.90:1; accent 3.22; canvas secondary text 3.64 (style.css:318–320). All other themes pass.
28. **C — 12 of 13 `<dialog>`s have no accessible name** (title is a `div.dialog-title` with no `aria-labelledby`).
29. **C — Theme flashes on load.** `initTheme` runs at the end of the deferred module; dark/sepia users get a light first paint every load.
30. **C — 34 unlabelled form controls**, mostly the 9 font rows where one `<label>` wraps three controls (only the first `<select>` gets a name). Focusable `#lattice` canvas has no `:focus-visible` style; 3 unpaired `outline:none` (802, 3622, 4642). `prefers-reduced-motion`: 0 hits repo-wide.

32. **C — Heading order is broken** (h2, h2, h3, then the only h1 at index.html:208); 13 panels have no headings; 5 of 6 `<aside>`s lack `aria-label`.
33. **C — `docs/index.html` and `INTRODUCTION.md` are still forked** (INTRODUCTION has an "inspect interval names" section docs lacks); docs has zero links back to the app; `KEYBOARD.md` and `OVERVIEW.md` remain unpublished.

## 3. Fix before Phase 3 (ordered)

Each is small and independent of the scene-builder work; several would otherwise become scene-builder bugs.

1. **Audio (2, 1, 4):** guard the one-shot `stop` with `!voice.usesWorklet`; add a `stop` message and have both worklets `return false` once inactive and decayed; await `addModule` (or `console.warn` the fallback); pin worklet delivery with `?url` or an `assetsInlineLimit` exception.
2. **Node identity (8, 9):** move `noteSpellings` and `getDistanceNodeKey` onto the `grid:x,y,z` / `custom:x,y,z|slot` convention already used by `getSnapshotNodeKey`; add a reader that rewrites the old forms using the file's own range and custom-node order (fixture 32 is the test). Make `rebaseLatticeFromNode` shift every exponent-keyed store, or route it through the serialize → rebuild → apply path `rebuildLattice` already uses. Do this *before* the scene builder assigns ids.
3. **Snapshot semantics (5, 7, 13):** give `applyPresetState` a sparse mode that skips default-refill for recall, or pass explicit "keep current" values instead of deleting; add tombstones (or full per-slot state) to snapshot-set diffs and bump that format to `v: 2` with the `v: 1` reader kept; delete the dead `snapshot*` preset reader.
4. **Robustness (6, 12, 10):** try/catch around boot and hashchange apply with a user-visible message; wrap the three bare `localStorage` calls; route the two drag-move `updatePresetUrl` calls through the debounce and wrap `replaceState`.
5. **Renderer gap (14):** decide whether the comma overlay exports; if yes, add it to the SVG builder now so the scene builder inherits parity; if no, clear it in `setLayoutMode`.
6. **Shared core (15, 16, 17):** reject `num ≤ 0` in `normalizeRatioToOctave`; coerce `baseText` at pitch.js:347; align `hasAccidental` with `getAccidentalType`; add `Number.isSafeInteger` guards to `gcd`/`reduceFraction`; delete `analyzeCustomRatio` and both `reduceToOctave`s in favour of the imports; drop the two unused imports. Add tests for each edge (see §6).
7. **Bundle (22):** dynamic-import `custom-oscillators` on first custom-waveform selection (export the type list separately so the dropdown can populate); delete either the static import or the runtime fetch of `interval-names.json`. Removes ~1.1 MB from the critical path of both apps.
8. **URL-update misses (11):** wire tempo, pattern length/mode, and LFO play toggle through `bindPresetInputHandler`.

## 6. Test coverage gaps and what to add

What the 124 tests cover: codec round-trip over 43 Creator exports, 38 deck diagrams, 2 snapshot sets, 12 presets, plus 23 pitch.js cases. What nothing covers: `applyPresetState` semantics (load → save → load idempotence), `diffSnapshotState`/`mergeSnapshotState`, `normalizePresetStateWithDefaults`, URL-hash parsing through `URLSearchParams`, malformed-input robustness of any `apply*`, snapshot-set apply for either format, and the seven unversioned migrations already in the reader (`layout.textScale`, `customNodes[].exponents`, numeric piano-map refs, `triangles[].label`, `"flat"` spellings, `layout.zoom` without `view`, line-label font fallback). Presets use 11 layout keys that no Creator fixture has; those apply paths are untested by fixture.

Add now (pure, no DOM):
- Extract `diffSnapshotState`/`mergeSnapshotState` and `deepMergePresetState` to a module; test that a key present in base and absent in next survives a diff/merge cycle as *absent* (fails today, pins defect 7) and that sparse recall leaves `view` undefined (pins defect 5).
- For every fixture: `decode(new URLSearchParams('s=' + encode(s)).get('s'))` deep-equals `s`.
- Five tiny legacy-shape fixtures in `fixtures/legacy/`, one per unversioned migration, so Phase 4 has inputs.
- pitch.js: `normalizeRatioToOctave(0,1)` and `(-3,2)` return null; `getHejiAnnotationForAxisRatios(x, undefined)` doesn't throw; ±50 c boundary; `hasAccidental("Fx")`; `expLabel` past `maxSymbols`; 7² / 7³ pair glyphs; a JSON snapshot of `HEJI_RULES` and `TRUE_SPELLING_INTERVALS`.
- Replace `scripts/regression-smoke.mjs` with `tests/source-guards.test.js`: assert the `labelT` line appears exactly 3 times (renderer parity, stronger than "includes"); scope the two layout-reset guards to `resetLayoutToDefaults` (today any of four sites satisfies them). ## 7. Notes for Phase 3 (scene builder)

- Parity is better than June implied. Shared style helpers already feed both renderers; what's duplicated is *geometry and text composition*: edge trimming, label placement, HEJI glyph assembly (`drawHejiInline` vs `buildHejiSvgInline`), small-cent text (`drawTextWithSmallCent` vs `buildSvgTextWithSmallCent`), and measurement (`ctx.measureText` vs `measureSvgTextWidth` vs opentype outlining). The scene builder should own those four and emit primitives.
- Text measurement is the coupling point. `draw()` measures 4–5 strings per node per frame with no cache while the LFO rAF loop is live; the scene builder needs one cached `measure(text, font, size, weight)`. `textWidthCache` (1879) is the seed.
- Canvas-only by design (keep as an explicit interactive-overlay pass): hover/selection, key banners, analysis watermark, ratio wheel, distance-drag preview, non-layout grid/axes.
- Serialization reads 16 DOM controls directly. The scene builder must not read the DOM; pass a snapshot of those values in.
- Fix node identity (§3.2) first, or key scene elements by `getSnapshotNodeKey`.

## 8. Notes for Phase 4 (state, format, input)

- Separate "absent = default" from "absent = leave alone" in the applier.
- Honour `v` on load with a migration table; fold the seven ad-hoc migrations into `v0 → v1`; reject `v > current` with a message. Presets.json's 12 entries are the oldest-format states in the repo and make good migration fixtures.
- Make apply atomic: build, validate (finite numbers, enumerated strings for `waveform`/`mode`/`nodeShape`/`pageSize`/`keyboardMode`, non-null array entries), commit; on failure keep the session.
- URL sync: length ceiling (>8 kB → skip URL, prompt to save file); the layout share button's >3500 warning fires *after* the `replaceState`.
- `LAYOUT_DEFAULTS` vs `let` initializers disagree for `titleFont`/`creatorFont` ("Lexend" vs "Noto Serif"), masked only by `initLayoutFonts` running before `presetStateDefaults` is captured. Initialise from one source.
- Ten keydown listeners now, not eight; `initPresentationMode` adds two raw ones outside the `bindOptionalEvent` convention.
- Overtones: `lKeyHeld` never resets on blur; synchronous `localStorage` write on every slider tick; wheel handler schedules the URL update twice.
