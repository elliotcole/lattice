Just Intonation

Tuning Lattice

Elliot Cole

An interactive environment for building, hearing, playing, and publishing just intonation systems. Design tunings as ratio networks, hear them immediately, perform on them, and export publication-ready diagrams.

Screen recording: overview of the app

Try it

Click the nodes. Listen to them ring.

Build

Shift-click to place nodes. Drag to rearrange. Connections and interval labels appear automatically.

  • Any prime limit — 3 through 97
  • 2D and 3D views with custom axes
  • Higher-dimensional lattices via custom nodes
  • Find ratios, calculate intervals, visualize commas
Screen recording: building a lattice

Play

Every node is a playable pitch. Click, type, or send MIDI. The lattice becomes an instrument.

  • QWERTY keyboard with multiple mapping modes
  • MIDI input and output with MPE pitch bend
  • Sine, sawtooth, Karplus-Strong, soundfonts
  • Patterns, loops, snapshots, morph between states
Screen recording: playing the lattice

Publish

Export publication-ready lattice diagrams for scores, liner notes, articles, and teaching materials.

  • SVG and PDF export
  • Full typographic control — 44+ fonts
  • Custom text, labels, and annotation
  • Page size presets for standard formats
